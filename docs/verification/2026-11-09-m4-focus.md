## Checklist — M4-T05

- [x] Descriptor advertises `af_mode` (the A51 lists off/auto/continuous-picture/macro),
      `af_lock`, `af_regions` (`max_regions=1`), `af_trigger` and `focus_distance` (0..10)
- [x] `focus_distance` accepts a dioptre value in range and the reported actual follows
      (0.5 requested → 0.516 actual); the service implies `af_mode = OFF` in the same batch
- [x] `focus_distance` rejects values outside the lens range (`OUT_OF_RANGE`) and
      non-numbers (`INVALID_VALUE`)
- [x] `af_regions` accepts a normalized region, fills the default weight and remembers it
- [x] `af_regions` rejects rectangles outside normalized `[0,1]` with `OUT_OF_RANGE`
- [x] Tap-to-focus: `af_mode=1` + `af_regions` + `af_trigger=start` transitions
      `af_state` to `focused_locked` and reports `af_lock=true`
- [x] `af_lock=true` switches AF to one-shot (`af_mode=1`), starts a scan and reports the
      locked state; `af_lock=false` restores the previous mode (`af_mode=4`)
- [x] Setting `focus_distance` while locked clears `af_lock` and switches `af_mode` to OFF
- [x] `af_lock` rejects non-booleans and `af_trigger` rejects values other than
      `start`/`cancel`
- [x] Restoring `af_mode=4` returns to continuous AF (`af_state=passive_focused`)
- [x] No regressions in the existing control surface (descriptor and state still include
      the T02–T04 controls)
